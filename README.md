<h1>About</h1>
<p>This is just a little to do list project I made to keep myself organised.</p>
<p>It was made using HTML, CSS & JavaScript and was one of my first projects.</p>

<h2>Usage</h2>
<p>It's currently hosted at <a href="https://brettstodo.app/">brettstodo.app</a>.</p>
<p>Simply type the task in the first input box, select whether it is business or personal and click the "Add todo" button.</p>
<p>Once an item is added it will be displayed further down in a list with your other items.</p>
<p>Each item has a 'check box' to cross items off, an edit button and a delete button.</p>
<p>Everything is stored locally.</p>
